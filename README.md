# Expense Split and Settlement System

A web-based application for recording group expenses, splitting costs, calculating balances, and managing settlements between users.

## Features

- User registration and login
- Create and manage groups
- Add group members
- Add expenses
- Equal, percentage, and custom expense splitting
- Automatic balance calculation
- “Who owes whom” calculation
- Pending and completed settlements
- Expense history and reports

## How It Works

1. Users register and log in.
2. A group is created and members are added.
3. Expenses are recorded.
4. Expenses are split among members.
5. The system calculates individual balances.
6. The system generates settlement details.
7. Settlements can be marked as completed.
